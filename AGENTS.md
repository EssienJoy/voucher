# Voucherly engineering guide

Voucherly is a two-app monorepo typescript project with a Nextjs voucher-frontend and Node_js voucher_backend folders.

NPM is the package manager, each folder has its own `package.json`, `node_modules`, and env file — they're run and deployed independently.
